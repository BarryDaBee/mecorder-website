Privacy

Privacy

This page describes how the app is built today. A formal privacy policy will be published with the first public release.

Your recordings stay on your Mac

Recordings are saved as project packages in ~/Movies/MeCorder. Recording, editing, captions and export run on your Mac. MeCorder never uploads your video or audio.

What Accessibility reads

With Accessibility allowed, MeCorder reads the name and role of the element you click or point at (a button’s title, a field’s placeholder) so that Programs can target it. It never reads a field’s contents, and nothing from password fields. Text typed into fields is only kept if you turn on Record text typed into fields, which is off by default.

Keyboard

With Input Monitoring allowed, only shortcuts such as ⌘K are recorded, to show them on screen. Plain typing is never stored for shortcut display.

Optional AI features

The AI Director and the Ask box work offline with a built-in interpreter. If you add your own Anthropic API key, your instruction and a compact text summary of the project (event timings, element names, the current edit) are sent to Anthropic. Your video and audio are never sent.

Diagnostics

Crash reports and a log of recording events are kept on your Mac. You choose whether to attach them to a bug report.

This website

This site doesn’t use advertising trackers. Any analytics added later will be privacy-respecting and described here.
