Getting started

  1. 1
    Open the download

    Drag MeCorder into your Applications folder.

  2. 2
    Allow Screen Recording

    macOS asks the first time. Quit and reopen MeCorder after allowing it.

  3. 3
    Allow Accessibility (recommended)

    So clicks are recorded as named elements that Programs can target.

  4. 4
    Record

    Press Start Recording, or ⇧⌘R. Stop with ⇧⌘2.
